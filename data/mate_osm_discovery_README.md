# MATE OSM discovery feed — source, license, and safety

**Source:** © OpenStreetMap contributors. The original database is offered under
the **Open Database License 1.0 (ODbL)**.

- Attribution and license: https://www.openstreetmap.org/copyright
- ODbL text: https://opendatacommons.org/licenses/odbl/1-0/
- API used for bounded queries: https://overpass.private.coffee/
- Each record includes its own original OSM element permalink in `source_url`.

`mate_osm_discovery.csv` and `mate_osm_recent.csv` are a **separate,
public OSM-derived review-only data source**. The OSM-derived database
is available under ODbL, subject to any applicable share-alike requirements.
Do not merge it into the differently sourced Overture archive or treat it
as first-party business permission, a verified owner application, an
endorsed listing, or an email marketing list.

OSM names and websites are crowd-sourced and may be stale or wrong.
Every website/contact/solicitation decision must be reverified against the
operator's current official website and preferences before any outreach.
Candidates start with `mail_basis=UNVERIFIED`, empty `email`, and empty
`contact_url`. This read-only process never extracts phones, sends
email, submits contact forms, registers businesses, or approves contracts.

No public-facing reference listing should be created from these records
without a separate check that the factual information is accurate and
presented as an unapproved editorial reference, not as owner-approved.
