# MATE 無料集客・SEO実行計画（2026-10-29）

## 公開済みの施策
- CARE GitHub Pagesの robots.txt と sitemap.xml を追加。GitHub Pagesへの反映と外部アクセスは別途確認。
- Search Console登録・サイトマップ送信はGoogleアカウント所有者の確認が必要。独自ドメイン切替時にcanonicalとURLを移行。
- 許諾を得ていないCARE候補やSPARK/PLAYのデモを実在の掲載ページとしてインデックス化しない。

## 優先順位
1. CARE・SPARK・PLAYそれぞれに適切なtitle, description, canonical, OG画像, h1、内部リンク、公開データに応じた構造化データを実装。登録済み実在ページのみサイトマップに掲載。
2. Search Consoleで各公開URLプロパティを所有者確認し、サイトマップ送信、インデックス状況と検索クエリを週次確認。
3. Google Analytics 4で3サイト別のpage_viewと送信完了・外部遷移イベントを測定。個人情報を送らない。
4. 親向けの独自記事：ベビーシッターの選び方、年齢別習い事、雨の日の親子お出かけ、地域別比較、料金と安全面、初回利用チェックリスト。事実確認と実体験を重視し、架空掲載を作らない。
5. 無料導線：InstagramとThreadsで記事を要約してサイトへ、noteで編集記事から適切にリンク、Pinterestはオリジナル画像を使う場合のみ、地域の子育て関連コミュニティは規約を確認して投稿。事業者が許諾した後に公式ページからの相互リンクをお願いする。
6. MEOは実在する対面対応の事業所・所在地・直接の顧客対応実態がGoogleの適格要件を満たす場合のみGoogleビジネスプロフィールを検討。オンラインのみの比較サイトを架空住所で登録しない。
7. 月次KPI：自然検索表示回数・クリック・CTR、記事別の訪問、掲載申請、相談の有効受付、実際の許諾掲載、取次成果。流入チャネルはUTMで区別。

## オーナー操作と安全確認
- PLAY元CMSのソースとFirebase静的版の差分が未解消。Firebaseテスト環境を現行PLAYに上書きしない。
- CARE実メールとSheetsの受付番号照合は専用Gmail権限または実受信証跡が必要。
- GA4リアルタイムはGA4の管理画面での表示、または対応する読み取り権限で確認。
- SNS・note・Googleビジネスプロフィールなど外部アカウントへの投稿や開設は本人のアカウント権限・最終確認後に実施。
