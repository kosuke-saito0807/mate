# MATE PLAY 公開連携の実装計画（未デプロイ）
更新: 2026-10-25

## 確認済みの事実
- 公開サイト https://mate-play.kosuke-saito0807.chatgpt.site/ は所有者の目視で正常表示、体験数0件。
- 所有者は正式な体験情報をまだ登録していない認識。
- Google Sheets「掲載セルフ申請」にPLAYの運営テスト1件が存在し、「差戻し」。掲載は禁止。
- 現行GitHub `play-listing.html` は掲載申請受付であり、PLAY公開CMSへの自動投入処理ではない。
- `scripts/mate_self_service.gs` の `publishReviewedMateApplications()` はPLAYを対象外としている。

## 実装前提
1. PLAYの公開サイトの編集元（原本）、CMSのデータ形式、認証、公開操作の仕様を確認。現サイトに実在掲載が無いからといって原本確認なしで置換しない。
2. 申請データの公開フィールドを明示的に限定: 体験名、開催地域、カテゴリ、対象年齢、概要、料金メモ、開催日、公式URL、利用許諾済画像参照、公開ID、確認日。担当者名・メール・電話・申請時刻・内部メモは除外。
3. ステータス遷移: 未審査 → 審査中 → 公開許諾確認 → 公開待ち → 公開中 / 差戻し / 取下げ。シート審査だけで自動的に公開しない。
4. 本番更新処理は二段階: 公開用JSONを検証・生成 → 差分をレビュー → 原本CMSに反映。公開先の認証・移行計画が明確になるまでは自動送信・公開を無効化。
5. 二重掲載防止: 受付IDを内部照合キーとして保持し、公開IDは独立採番。再実行時は同じ公開IDを更新。取り下げ時は非掲載にする。
6. 画像の権利確認とイベント開催期限切れ表示を公開前に必須とする。

## 受け入れ条件
- 未審査/差戻し/内部QAは0件として公開データに出ない。
- 審査済み・許諾済みの1件だけが公開され、同じ受付ID再実行でも1件を維持。
- 別の事業者の連絡先は一切公開されない。
- 取下げが公開サイトに伝播する。
- 誤公開が生じた場合のロールバック手順とバックアップを検証済み。
- PC/スマホ両方で掲載確認、リンク切れや画像欠落なし。

## 進め方
現在は公開先CMSの原本と書込仕様を確認できていないため、**本番PLAYに対する更新・置換は実施しない**。まず必要情報を入手してから、ステージングで非公開サンプル検証を行う。
