# CARE SCENE photo assets

The existing first-party photos prepared for the 2026-10-31 CARE preview are used for the three scenes:
- assets/mate-care-scene-urgent.webp — urgent sitting
- assets/mate-care-scene-pickup.webp — nursery school pickup
- assets/mate-care-scene-sick.webp — care for an unwell child

The work-from-home card keeps assets/mate-work-sharp-complete-20261013.png.

All cards have proportional photo frames; these images illustrate scenarios, not
actual MATE clients, partner services or contracted caregivers. The existing
assets ship directly with GitHub Pages: no external CDN or build-time download
is needed. Original source/usage rights should be reviewed before external
marketing use. The temporary Pexels photo plan is not used.
