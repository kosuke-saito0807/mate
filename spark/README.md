# MATE SPARK 比較・体験申込機能（初期実装）

- `spark/index.html`: 都道府県・年齢・ジャンル・キーワード絞り込みと複数教室の比較。
- `spark/schools.json`: **掲載許可済み**の教室だけ登録する公開専用データ。
- 現在は **体験申込ボタンを意図的に無効** にしています。保護者の個人情報を静的サイトやGitHubへ保存しないためです。
- MATE CARE 本体の `index.html` は変更していません。SPARK独立ドメインへの適用は別作業です。

## 登録データ例
```json
[{"id":"unique-code","name":"教室名","region":"東京都","station":"駒込","category":"学習塾","ages":["小学生","中学生"],"description":"説明","url":"https://example.com/","approved":true}]
```

## 受付を公開する前の必須作業
1. 実際のMATE SPARK公開リポジトリへ統合し、ブランド・既存掲載DBと接続。
2. 申込受付の契約と掲載教室の同意を確認。
3. サーバー側APIを設定し、入力検証、同意ログ、スパム防止、アクセス制御を導入。
4. 管理者宛通知・教室への個別通知（各教室には自教室の申込だけ）・送信失敗時の再試行を実装。
5. プライバシーポリシーに共同利用/第三者提供の範囲、送信先、保管・削除を明示して公開前にテスト。

GitHub Pages 単体では秘密鍵管理や安全な個人情報の受付処理を実装できません。
